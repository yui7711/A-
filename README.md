## 数据连接

- 自动刷新默认 5 秒，支持 5/10/30/60/300 秒、手动刷新与日夜模式。
- 同花顺兼容源 FUYAO（`https://fuyao.aicubes.cn`）：使用用户参考站提供的 X-api-key 接口。尚未验证其与同花顺官方的关系，不能与 iFinD Token 混用。
- 优先通过本站既有 Sites 服务端代理 `/api/market` 取数。仅放行 `https://yui7711.github.io` 读取公开行情，浏览器不携带密钥或登录凭据。
- 仓库 Secret `FUYAO_API_KEY` 仅注入 Actions 的采集步骤。采集模块位于 `A-/scripts/fuyao-data.mjs`，不进入浏览器依赖；只发布归一化行情，不发布凭证或原始响应。
- 每次刷新立即访问服务端实时 API，不等待 GitHub Actions。默认每 5 秒发起请求，禁止并发重入；请求较慢时在完成后继续。数据来源页继续刷新，后台标签页暂停。已取消 5 分钟定时部署；构建快照仅用于离线或断线兜底。
- 连接失败保留具体原因：网站服务端 HTTP 状态、超时与浏览器网络异常不推断为 Key 失效；上游明确返回时才标记 Key 无效（2001）、权限不足（2003）或限流（4001/429）。腾讯单日分时异常时，改读五日分时的最新一日，不拼接不同交易日。
- 主服务失败或2.5秒未及时响应时，启动东方财富 / 腾讯独立直连；完整公开池优先于同日旧构建快照，池、统计和历史证据保持同一套数据。数据来源页可选“公开行情直连（跳过服务端）”，选择仅保存在本机。浏览器不使用私有Key，失去竞速的服务端请求会取消。
- 直连六维使用腾讯沪深同一分钟的两日累计成交额；已核实的上一交易日完整名单来自本站 `data/history.json`，两日股票使用同一份东方财富当前行业映射。行业归属不冒充涨停原因。历史文件每个工作日北京时间09:10由 Actions 更新最近三个已结束交易日；GitHub调度可能延后，该任务只补历史，盘中行情仍每5秒独立请求。历史日期或数量不完整时暂停对应评分。
- 盘前与休市按指数实际日期显式查询同一交易日的涨停池、统计、跌停池与炸板池；开盘切换当天。健康空池不会恢复成昨日名单。实时成功优先于任何构建快照；辅助模块失败不阻断其他模块。缺失字段按同日同代码从东方财富补充，跨日值不混用。
- 东方财富、腾讯继续提供公开涨停/炸板/跌停、行业、龙虎榜、报价与真实图表。东方财富备用池只返回行业，题材按行业近似。通达信保留本机自选文件导入。
- 情绪六维、主线去噪、三大战法与今明条件计划沿用原版；缺失维度仍待验证。缺失数据不填零、不生成演示行情。

## 发布

取得仓库写入权限后，将本包合并到目标仓库，先检查并保留仓库现有文件及 Pages 配置。默认分支为 main/master 时，推送后工作流会测试、采集公开快照、构建并发布。其他默认分支需同步修改工作流分支。

在仓库 Settings → Pages 中将 Source 设为 GitHub Actions。保留仓库原来的可见性；如果当前账户套餐不支持私有仓库 Pages，需要由仓库所有者决定后续处理，不能自行公开原有仓库历史。以工作流返回的发布地址为准。

`A-/outputs/index.html` 为额外生成的单文件网页，可作为仅发布静态页面的备选；它内嵌真实行情快照，并继续直接刷新公开行情。源码和正常 Pages 工作流是主要交付内容。

## 复制到其他电脑直接打开

不要直接打开源码入口 `A-/index.html`，它需要 Vite 构建。请复制生成的 `A-/outputs/index.html`（也已另存为“曜石市场雷达-直接打开.html”）这个实际文件到其他电脑，然后用 Edge / Chrome 打开。只复制 `F:/...` 路径不会传输文件，这个路径不是公网地址。单文件内嵌界面和真实行情快照，无需安装 Node 或启动服务；获取最新行情、图表需要联网，断网时显示内嵌快照的原始日期。


战法状态使用明确操作含义：蓝色“优先/备选研究”只建立观察名单，买点未确认；黄色“等待确认”表示条件未齐，暂不据此新开仓；红色“暂停参与”替代原“防守优先”，风控触发时不按战法新开仓；灰色“不适用/数据待更新”分别表示不采用或无法判断。四项环境筛选必须全部满足才标可研究，完整同日统计、四指数时效与风控先于排序。单项4/4不能绕过风险门槛；本站没有“可直接买入”等级。


六维规则 v2 已接入历史证据：腾讯沪深五日分时累计成交额作为同刻量能主源，东方财富五日分时（逐分钟金额转累计）为备用，仅在收盘时允许 FUYAO 指数日线作金额备份。两指数、两日期必须共有同一截点。上一交易日由实际交易日历确定，历史涨停名单使用 FUYAO 分页完整池，失败时以日期核验过的东方财富完整池补充；晋级率按非 ST 股票代码逐股取交集。

涨停原因未齐时，当前和历史名单统一使用同花顺当前行业归属映射。行业对照不冒充历史涨停原因，也不混用行业和题材口径。量能评分为同刻金额比的规则分 70% + 昨日前三主线保留比例 30%；晋级评分为逐股晋级率×20（上限10）。每维显示来源、日期和截点；数据不完整、金额分母为零或盘中分时超过3分钟时不硬填数。新对照缓存仅保存已完成数据，不改变五秒实时行情轮询。
